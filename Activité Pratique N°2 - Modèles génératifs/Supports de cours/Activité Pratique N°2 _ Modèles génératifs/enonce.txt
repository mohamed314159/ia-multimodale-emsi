Configuration d’un environnement Python avec UV dans VS Code
- Créer un dossier.
- Ouvrir ce dossier dans VS Code.
- Ouvrir le Terminal et exécuter les commandes suivantes :

> uv init --python=3.11
> uv venv
> Activer l'environnement : .venv/Script/Activate ou source .venv/bin/activate
> uv add ipykernel
> uv add torch
> uv add torchvision
> uv add matplotlib

- Créer un nouveau Notebook Jupyter (.ipynb).
- Écrire votre code Python dans le Notebook.
